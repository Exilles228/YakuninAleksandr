# Сайт Александра Якунина — стилист-визажист

Сайт-портфолио в стиле «тёмная роскошь» (чёрный + акцентный цвет) с онлайн-записью на свободное
время и **панелью мастера**, где редактируется всё: записи, расписание, услуги и цены, портфолио,
тексты, контакты, отзывы, музыка, цвета, разделы, логотип, SEO, политика конфиденциальности.

Всё бесплатно: сайт — статичные файлы (любой бесплатный хостинг), данные — в Google Таблице
мастера, фото и музыка — в его Google Диске, записи — в его Google Календаре, письма — с его Gmail.

```
index.html            страница сайта
css/style.css         стили (сайт + панель мастера)
js/config.js          ← адрес бэкенда (API_URL)
js/core.js            общая логика, расчёт свободного времени, связь с бэкендом, демо-режим
js/app.js             сайт: разделы-экраны, портфолио, цены, запись, контакты, плеер, курсор
js/admin.js           панель мастера
img/                  логотип (logo_square.jpg) и иконка (logo_ya.jpg)
apps-script/Code.gs   бэкенд (Google Apps Script)
```

## Посмотреть без настройки (демо-режим)

Если в `js/config.js` пустой `API_URL`, всё работает в браузере без сервера (пароль панели — `admin`).
Локально: `python -m http.server 5173` → http://localhost:5173

## ⚠️ Обновление уже подключённого бэкенда (обязательно!)

Если в панели мастера не подходит пароль `yakunin2026` или при записи пишет «Выберите услугу» —
на сервере работает **старая версия скрипта**. Проверить: откройте в браузере
`<ваш API_URL>?action=version` — должно показать `"version":4`. Если пишет «Неизвестное действие» — обновите:

1. Откройте таблицу → **Расширения → Apps Script** → выделите весь старый код (Ctrl+A) → удалите →
   вставьте весь новый `apps-script/Code.gs` → 💾 **Сохранить**.
2. Вверху выберите функцию **`setup`** → **Выполнить**. В журнале должны быть строки с ✓.
   (Если Google попросит разрешения — разрешите.)
3. **Развернуть → Управление развёртываниями** → выберите текущее развёртывание → ✏️ (карандаш) →
   в поле «Версия» выберите **«Новая версия»** → **Развернуть**.
   ⚠️ Без этого шага Google продолжает выполнять старый код, даже если новый сохранён.
4. Снова откройте `<API_URL>?action=version` — должно быть `"version":4`.

Адрес не меняется, `config.js` трогать не нужно. Пароль панели по умолчанию — `yakunin2026`.

## Первое подключение (≈15 минут, в Google-аккаунте мастера)

### 1. Таблица + скрипт
1. https://sheets.new → назовите «Сайт — записи».
2. **Расширения → Apps Script** → вставьте `apps-script/Code.gs` вместо всего кода → 💾.
3. ⚙️ **Настройки проекта** → часовой пояс *(GMT+03:00) Москва*.
4. Функция **`setup`** → **Выполнить** → разрешить доступ («Дополнительные настройки» →
   «Перейти на страницу проекта» → «Разрешить»). В журнале: «Готово! Пароль: yakunin2026».

### 2. Веб-приложение
**Развернуть → Новое развёртывание → Веб-приложение**, «Запуск от имени: Я», «Доступ: Все» →
скопируйте URL (`https://script.google.com/macros/s/…/exec`) в `js/config.js` → `API_URL`.

### 3. Хостинг
https://app.netlify.com/drop — перетащите папку проекта (или GitHub Pages).

### 4. Первый вход
Сайт → внизу «Вход для мастера» (или `адрес/#admin`) → `yakunin2026` →
**Уведомления → Пароль** — смените. Затем **Настройки сайта → Адрес сайта** проверьте, что там
ваш адрес (заполняется сам при первом сохранении) — он нужен для ссылок в письмах.

## Как это работает для мастера

**Новая запись →** письмо на Gmail + событие «🆕» в Google Календаре + строка в таблице.
Если клиент указал e-mail — ему сразу уходит письмо «Заявка получена».

**Подтвердить прямо из письма** — в письме о новой записи есть кнопки «✓ Подтвердить» и «✕ Отказать»: откроется страница с деталями, одно нажатие — и статус в таблице и календаре изменится, клиенту уйдёт письмо. Или **Подтвердить** в панели (Панель → Записи) → клиенту автоматически уходит письмо с подтверждением
и файлом для календаря; открывается окно с готовым текстом для SMS (с вашего телефона — бесплатно).
Накануне визита клиенту приходит письмо-напоминание, вам — вечерняя сводка на завтра.

**Отзывы.** В письмах клиенту есть ссылка «Оставить отзыв», а после отметки «Выполнена» клиенту приходит отдельная просьба. Новый отзыв приходит вам на почту с кнопками «Опубликовать» / «Скрыть» (или Панель → Отзывы). Опубликованные отзывы появляются на сайте с пометкой «Подтверждённый визит».

**В каждом письме клиенту есть кнопка «Отменить запись»** — время освобождается само,
вам приходит уведомление. История писем видна в карточке записи.

**Расписание →** календарь: нажмите на день → выходной / особые часы / закрыть часть времени.
Или просто создайте событие в Google Календаре — это время закроется на сайте (в течение ~10 минут).

**Клиент позвонил →** Записи → «Добавить запись».

### Автоматические SMS (по желанию, платно)
Бесплатных сервисов автоотправки SMS в РФ нет. Если нужно — https://sms.ru, API-ключ в
Панель → Уведомления. Бесплатная альтернатива — письма на e-mail (включены) и кнопка SMS в панели.

## Обслуживание

- **Изменили `Code.gs`** → Развернуть → Управление развёртываниями → ✏️ → Новая версия.
- **Изменили CSS/JS** → увеличьте `?v=2` → `?v=3` в `index.html`.
- **Забыли пароль** → Apps Script → функция `resetPassword` → Выполнить (станет `yakunin2026`).
- **Резервная копия** → Панель → Настройки сайта → «Скачать резервную копию».
- Таблицу можно смотреть и править вручную, но не меняйте заголовки и порядок столбцов.
- Лимиты Google (бесплатно): ~100 писем в день.
- Музыка по умолчанию — записи классики из общественного достояния (Wikimedia Commons).
